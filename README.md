# CodeWithMfari — Retail Technology

A responsive React + Vite website for CodeWithMfari, focused on practical digital tools for grocery shops, mini-marts, foodstuff stores and distributors.

## Features
- Responsive landing page and mobile navigation
- Retail technology services and illustrative dashboard concept
- Process, portfolio and FAQ sections
- WhatsApp contact CTA: +234 911 033 9814

## Development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

The dashboard figures are illustrative sample data, not live customer business data.
